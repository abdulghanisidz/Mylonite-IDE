SECTION 10 — IMPORTANT ARCHITECTURE DECISIONS (QUICK REFERENCE)
────────────────────────────────────────────────────────────────────────────────

  ADR-001  Flutter for UI              Cross-platform; single codebase; good perf
  ADR-002  llama.cpp for inference     Most mature ARM64 LLM engine; GGUF; MIT
  ADR-003  QuickJS for V1 JavaScript   ~200KB; ES2020; no JIT restrictions; no npm
  ADR-004  Dart FFI for llama.cpp      Avoids JNI double bridge; token-gen perf
  ADR-005  No database in V1           JSON files sufficient; no migration overhead
  ADR-006  Stateless inference         Simpler; no KV cache management; post-V1 opt
  ADR-007  No required fine-tuning     Any instruction-following GGUF model works

  KEY CONSTRAINTS:
  - noexec: Python binary must be in nativeLibraryDir (as libpython3.so)
  - No root: all operations within app sandbox
  - No system shell: all terminal interactions via RuntimeManager, not /bin/sh
  - API keys never in Dart: EncryptedSharedPreferences in Kotlin only
  - Path confinement: 2-layer (ToolExecutor + WorkspaceManager)
  - AI context budget: 75% of model context window, 1024 token output reserve

  OFFLINE-FIRST INVARIANT:
  - All core features work with no internet connection
  - Internet only needed for: initial runtime/model download, cloud AI (optional),
    pip package install, npm (future)
