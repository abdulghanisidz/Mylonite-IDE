The Problem

Modern smartphones have more compute power than desktop computers from a decade ago — yet they remain essentially useless as development tools. Every serious coding environment requires a laptop, a desktop, and usually a reliable internet connection.

🚫

No local runtimes

Android ships no Python, Node.js, or general-purpose language interpreter. There's no python3 or node in the system.

📡

Cloud-only AI tools

Every AI coding assistant on mobile requires a cloud API. Zero offline capability. Zero privacy. Useless without Wi-Fi.

📱

Desktop ports don't work

Attempting to run VS Code on a phone produces an unusable experience. The UX, architecture, and features must be rethought for mobile.

What Mylonite IDE Does

A complete development environment — entirely on your Android device, entirely offline.

✍️

Code Editor

Syntax highlighting for Python and JavaScript via flutter_code_editor. Line numbers, undo/redo (200-step), dirty indicators, multi-tab support.

🔍

In-file Search

Find text or regex patterns across the open file. Navigate matches, toggle case sensitivity — no internet, no server.

📁

Project & File Manager

Create, open, rename, delete files and folders. Persistent projects with metadata. Path-confinement security prevents any access outside the workspace.

📦

ZIP Import / Export

Import projects from ZIP archives. Export any project as a ZIP. Zip-slip attack protection and ZIP bomb guards built in.

👁️

File Watcher

Polling-based file change detection. The Explorer auto-refreshes when files change — no manual refresh needed.

🤖

AI Diff Preview

When the AI agent proposes a code change, a diff banner appears with Accept and Reject buttons. You stay in control.

🔒

Security First

Workspace sandboxing, symlink-escape protection, ZIP-slip guards, encrypted API key storage, and a full audit trail of agent actions.

🌑

Offline First

Every core feature — editing, file management, project creation, AI agent — works with no internet connection. Cloud is optional, never required.

⚡

Built for Android

Respects Android process lifecycle, foreground services for long operations, and ARM64 NEON-optimised AI inference.

Architecture

Five clean layers. Each is independently replaceable. No layer depends on a concrete implementation below it — only on an interface.

UI LayerFlutter / Dart — Screens, widgets, navigation (go_router)
↕
Application CoreDart — ProjectManager, WorkspaceManager, EditorController, AgentController, AIProviderManager
↕
Platform BridgeFlutter Platform Channels + Dart FFI — Android API access
↕
Native ServicesKotlin / Android SDK — ProcessManager, SAF, Memory, Thermal, Keystore
↕
Compute EnginesC/C++ — llama.cpp (AI), CPython ARM64, QuickJS, File Index

The agent communicates only through the ToolRegistry — a controlled allowlist of 13 tools. Every destructive action passes through the ConfirmationGate. All file paths are validated by WorkspaceManager before touching the filesystem.

Security Model

Security is a first-class requirement, not an afterthought.

🛡️

Workspace Sandboxing

The AI agent can only access files inside the active project directory. Path traversal and symlink escape attempts are blocked at two independent layers.

🔐

Encrypted Key Storage

API keys are stored in Android Keystore via EncryptedSharedPreferences. They never appear in Dart memory, logs, or the LLM context.

📋

Audit Trail

Every agent tool call is logged with timestamp, parameters, and outcome. Security events (path traversal attempts, rejected operations) are flagged separately.

💉

Prompt Injection Defence

File content is wrapped in data markers before entering the LLM context. The system prompt explicitly instructs the model to treat file content as data, not instructions.

✅

Confirmation Gate

Destructive operations (delete file, delete directory, bulk modification) always require explicit user confirmation regardless of who initiated them.

🗜️

ZIP Slip Protection

ZIP imports are validated against path traversal, bomb attacks (>10k entries, >500MB), null bytes, and absolute paths before any byte is written.
